# Writing reminder & event titles

Rewrite before saving. The lock-screen line is the product.

## Clarity

- Lead with a concrete verb: Call, Send, Draft, Buy, Book, Review, Ship
- Name the object specifically: "Ship slice-12 PR" not "finish the thing"
- Drop filler: please / just / somehow / later / asap (put timing in the due date)

## Emotions

- When the reason is human, say so briefly
- Prefer honest stakes over fake urgency
- Examples:
  - ❌ "Text Amanda"
  - ✅ "Text Amanda — check how she's feeling after yesterday"
  - ❌ "Workout"
  - ✅ "Walk outside — reset before evening spiral"

Only add emotional color when it helps future-you care. Don't invent melodrama.

## Logic

- If "done" is ambiguous, make the done-state obvious
- Prefer outcome over activity when both fit
- Examples:
  - ❌ "Taxes"
  - ✅ "Upload March receipts to accountant folder"
  - ❌ "Session card refactor"
  - ✅ "Split CalmCard families into their own views"

## Meaningfulness

- Ask: would I thank past-me for this wording?
- Tie chores to the value they protect when it's real
- Avoid corporate mush ("synergize", "leverage", "circle back")

## Notes field

Use `--notes` for:

- Links, file paths, PR numbers
- Constraints ("after standup", "needs quiet 45m")
- Source context from the chat (one line)

Do not dump the whole conversation.
